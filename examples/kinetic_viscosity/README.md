# 座標を変えたD2Q9の衝突と粘性の検証

高精度化した有限体積輸送に，BGK衝突項（分布を同じ密度・運動量の平衡分布へ
近づける項）を加える．波へ組み込む前に，一様流の維持，衝突だけによる緩和，
粘性によるせん断流の減衰を調べる．せん断流は，横方向の位置によって縦方向の速さが
変わる流れである．初期条件・参照値・幾何・時間積分・診断値をすべてFMEに記述し，
通常の `.fme → Egison → FEIR → .fmr → Formura → C` を使う．
FormuraeとFormuraの構文・処理系は変更しない．

## 方程式と座標の分離

物理空間の固定した九方向を `c_a`，分布を `f_a` として，

```text
∂t f_a + div(c_a f_a) = (f_eq,a − f_a)/τ
ρ = Σ_a f_a,  ρu = Σ_a c_a f_a
f_eq,a = w_a ρ [1 + 3(c_a·u) + 9(c_a·u)²/2 − 3(u·u)/2]
```

を解く．`τ` は連続時間の緩和時間である．長い波長・小さい速度の極限では
動粘性係数は `ν = τ/3` になる．格子間の厳密な移動を前提とする標準LBMの
`(τ−dt/2)/3` を，今回の時間積分に流用しない．モデルとこの区別については
[Reider・Sterlingの§2，式(3)〜(9)](https://arxiv.org/html/comp-gas/9307003v1)を参照．

衝突の内積には，物理空間に固定した正規直交基底（互いに直角な単位ベクトル）を使う．
FMEの添字 `p` はこの基底の二成分，`a` は九方向の番号，輸送の `i` は計算座標の方向を表す．
`frame` は物理的な九方向の成分であり，曲がった格子でも変えない．
`u~p . u_p` などの内積を同じ基底で取り，密度と運動量から平衡分布を作る．
計算座標の成分を正規直交成分として扱うものではない．

格子は既存の[有限体積輸送](../kinetic_fv/README.md)と同じで，
`X=x+ax sin(x)sin(y), Y=y+ay sin(x)sin(y)` を使う．
直交格子は `(ax,ay)=(0,0)`，曲がった格子は `(0.2,0.15)`．
座標写像からセル面積と面の向き・長さを作り，両方の格子に同じ輸送・衝突を適用する．
物理的な九方向の近似は固定しており，任意の回転に対する厳密な等方性を主張しない．

## 輸送と時間積分

セル内の傾きを制限するMC制限付きMUSCL法と，一次風上法を比較する．
MUSCL法はセル内を直線で近似して面の値を求め，MC制限は急な変化で傾きを抑える．
`sampleLower`／`sampleUpper` で値を選び，セルが共有する面の流量を計算する．
両方の方法で，輸送と衝突を同じ段階で評価する二段の時間積分SSPRK2を使う．

```text
L(f) = transport(f) + (equilibrium(f) − f)/τ
v = f + dt L(f)
w = v + dt L(v)
f_next = (f + w)/2
```

平衡分布が非負である場合，MUSCL法のEuler更新の非負性の十分条件は
`2C + dt/τ ≤ 1` である．`C` は時間刻みと外向きの面の流量係数から求める値で，
輸送だけの検証で使ったものと同じである．一次風上法は `C + dt/τ ≤ 1`．
両方のEuler候補，保存した状態，平衡分布の最小値を計測する．値の切り詰めは行わない．
衝突は方向間で量を交換するため，保存を調べるのは九方向それぞれの総量ではなく，
合計の質量と物理的な運動量である．

## 減衰の参照値を導く

周期領域 `[0,2π)²` で密度1，`u_X=0`，`u_Y=A exp(−rt) sin(X)` を考える．
波数は1，振幅は `A=0.02` とする．九方向の方程式から，次の三つの量の閉じた式が得られる．

```text
j = Σ_a cY_a f_a, P = Σ_a cX_a cY_a f_a, Q = Σ_a cX_a² cY_a f_a
∂t j = −∂X P
∂t P = −∂X Q − P/τ
∂t Q = −∂X P − (Q − j/3)/τ
```

`j=A exp(−rt) sin(X)`，`P=−r A exp(−rt) cos(X)` を代入すると，

```text
r(1−rτ)² = τ(1/3−rτ)
```

を得る．この関係を満たす減衰の遅い解を，`z=rτ` を指定して
`τ=sqrt(z(1−z)²/(1/3−z))`，`r=z/τ` と表す．
`z=0.002, 0.008, 0.02` の三条件を使う．方程式から求めた値であり，計算結果への当てはめではない．
この有限波長の減衰率 `r` は，長波長極限の `τ/3` とわずかに異なる．
両方をFMEから出力し，格子誤差とこのモデル自体の差を混同しない．

初期分布には，平衡の静止分布に次の成分を加える．

```text
δf_a = 3 w_a cY_a A [(1−z) sin(X) − τ cX_a cos(X)]
       / [(1−z)² + (τ cX_a)²]
```

これは最初から上記の減衰を選ぶための初期条件である．二次の平衡分布の
非線形項は `cY` に関して偶対称であり，この横向き運動量の三式には寄与しない．
また，各 `cX` について `cY` 方向を合計した分布は静止平衡を維持するため，
連続方程式では密度1と `u_X=0` が保たれる．したがって参照するのは速度の解であり，
各分布全体がこの一次の摂動だけで減衰すると仮定するものではない．

セル平均の正弦・余弦には，四角形セル上の四点Gauss積分を使う．
`mode` は `2∫ u_Y〈sin X〉 dA / domainArea`，`referenceMode` は同じ投影を
参照速度に適用した値である．`〈sin X〉` はセル平均で，両方に同じ積分を使う．
`modeError` はその差を初期振幅Aで割った値である．誤差・投影・保存量の計算はFMEで行う．
`velocityError` は二つの速度成分の絶対誤差の最大値，`velocityErrorL1` は
二成分の絶対誤差の和を物理面積で平均した値である．

## 検証条件

16×16，32×32，64×64，128×128セル，二つの格子で次を比較する．

- 一様流：密度1，速度 `(0.03,0.02)` の平衡分布を維持する．
- 空間的に一様な衝突：`f_a=w_a[1+A(cX_a²−1/3)exp(−t/τ)]` と比較する．
  密度・運動量は変わらず，平衡からのずれだけが減衰する．
- せん断流：三つの緩和時間で参照解への収束を調べる．中央の条件では
  一次風上法も比較し，64セルでは時間刻みを半分にした計算も行う．

計50条件．通常の `dt=0.1 hx hy/(hx+hy)` を使い，一様流と衝突だけの問題は
`t=0.2π`，せん断流は `t=2π` まで計算する．全中間段階の診断をCSVへ保存する．

合格条件は，質量の相対変化と運動量の絶対変化が `2×10⁻¹¹` 未満，
一様流の誤差が `2×10⁻¹²` 未満，平衡分布の非負性，Euler候補を含む非負性，
上記の時間刻みの十分条件，密度の1からのずれが0.01未満である．
衝突だけの問題は収束次数1.8超，せん断流の速度誤差は最大・平均とも，最も細かい二つの格子の間で次数1超を求める．
64セルではMUSCL法の `abs(modeError)<0.03`，平均速度誤差が初期振幅の2%未満，
座標間の差が細分化で減ることを確認する．
中央の緩和時間では，一次風上法より平均速度誤差が半分未満になること，
時間刻みを半分にした際の `modeError` の変化が0.001未満であることも確認する．

最初の16〜64セルの検査では，`z=0.002` の直交格子で最大速度誤差の
32→64セルの収束次数が0.576にとどまり，次数1超の基準を満たさなかった．
同条件の平均速度誤差の次数は2.229だった．局所的な最大誤差の検査を残し，
128セルを追加して，最も細かい二つの格子で同じ合格基準を確認する構成とした．

## 測定結果（2026-09-18）

50条件の検査が通った．高精度法の速度誤差は次のとおり．
次数は64→128セルで評価する．最大誤差と平均誤差の両方が次数1超を満たした．

| 格子 | 緩和時間 τ | 64セルの平均誤差 | 128セルの平均誤差 | 最大／平均誤差の次数 |
|---|---:|---:|---:|---:|
| 直交 | 0.0775 | 9.1858e-06 | 1.3639e-06 | 3.494 / 2.752 |
| 直交 | 0.1556 | 8.2592e-06 | 1.4343e-06 | 2.518 / 2.526 |
| 直交 | 0.2476 | 7.8048e-06 | 1.6997e-06 | 2.312 / 2.199 |
| 曲がった格子 | 0.0775 | 8.8601e-06 | 1.5789e-06 | 3.041 / 2.488 |
| 曲がった格子 | 0.1556 | 8.8156e-06 | 1.8840e-06 | 1.632 / 2.226 |
| 曲がった格子 | 0.2476 | 8.8189e-06 | 1.9674e-06 | 1.707 / 2.164 |

128セルでの投影した速度の参照値との差は，初期振幅の最大0.0133%だった．
全条件の質量の相対変化は最大2.017e-13，運動量の絶対変化は最大3.810e-16．
両Euler候補と平衡分布に負値はなく，非負性の十分条件の左辺は最大0.495595（上限1）だった．

64セルの直交格子では，同じ時間積分の一次風上法に対し，平均速度誤差は約102.4分の1．
時間刻みを半分にした際の `modeError` の変化は1.506e-09だった．
64セルの曲がった格子では，同じ時間積分の一次風上法に対し，平均速度誤差は約110.9分の1．
時間刻みを半分にした際の `modeError` の変化は1.791e-09だった．

衝突だけの緩和も，両格子で二次精度に対応する誤差減少を確認した．
これは周期領域の粘性流の検証である．重力下の静水と水平な壁は
[`kinetic_hydrostatic`](../kinetic_hydrostatic/README.md)で検証し，自由表面へ進む．

## 実行

```sh
make kinetic-viscosity-verify
make kinetic-viscosity-gallery
```

小さい試験は `python3 examples/kinetic_viscosity/run.py --grids 16`．
FMEと処理系が一致する正規化結果は `--reuse-normalized` で再利用できる．
ビルド・計算は直列に行う．Cは設定と生成ソルバーの呼び出し・出力，Pythonは
ビルド・起動・保存済み診断の検査と描画のみを担当する．
今回は単一プロセスで検証する．MPIによる領域分割と，複数ステップをまとめて計算する
時間方向のブロッキングは，この例ではまだ検証していない．

重力と静水，水平な壁の検証を経て，水面の更新を加える．波の動画への結合や，
水際の後退の改善をこの実験だけで確認したとは扱わない．
