# 重力と圧力がつり合う静水，壁での反射

`kinetic_viscosity` の有限体積輸送と衝突を，重力と上下の壁がある領域へ進める．
有限体積法は，セルの面を通る流量からセル内の平均値を更新する方法である．
直交格子と曲がった格子で同じ物理モデルを使う．初期条件，境界処理，
時間積分，診断値まで `kinetic_hydrostatic.fme` に記述し，通常の
`.fme → Egison → FEIR → .fmr → Formura → C` を通す．処理系は変更しない．

## 方程式と静水状態

D2Q9は，二次元の九方向の分布から密度と運動量を求めるモデルである．
物理空間で固定した速度 `c_a`，重み `w_a`，緩和時間 `τ=0.16` を用い，

```
∂t f_a + div(c_a f_a) = (f_eq,a − f_a)/τ + S_a
ρ = Σ_a f_a，ρu = Σ_a c_a f_a
f_eq,a = w_a ρ [1 + 3 c_a·u + (9/2)(c_a·u)² − (3/2)|u|²]
S_a = w_a ρ [3(c_a − u)·g + 9(c_a·u)(c_a·g)]
```

を連続時間の方程式として解く．BGK衝突項 `(f_eq−f)/τ` は，同じ密度と
運動量を持つ平衡分布へ近づける項である．外力のモーメント（速度で重み付けした和）は
`ΣS_a=0`，`Σc_a S_a=ρg`，`Σc_a c_a S_a=ρ(ug+gu)` を満たす．
時間積分にはSSPRK2（二つのEuler更新を組み合わせる二次精度の方法）を使う．
Euler更新は，現在の時間微分に時間刻みを掛けて状態を一回進める操作である．
通常の格子点間の移動を用いるLBMの外力係数 `1−dt/(2τ)` や，
速度への半時間刻みの補正は使わない．
[Guoらの論文](https://doi.org/10.1103/PhysRevE.65.046308)は時間離散化の影響を
論じているが，本例では上記の連続時間の外力と，そのモーメントの恒等式から実装する．

基準の重力は `g=(0,−0.01)`，圧力は `p=ρ/3` である．
`∂Y p=−0.01ρ` の静水解は

```
ρH(Y) = exp(−3×0.01×Y)，fH,a = w_a ρH，uH = 0
```

となる．密度が高さとともに変わる，温度を一定とする圧縮性のあるモデルである．
本例の密度は底で1，上面で約0.828となる．重力と圧力のつり合いを調べるための
無次元の条件であり，実際の水の圧縮率を再現する設定ではない．
密度一定の非圧縮流体とは区別する．領域全体を流体で満たしており，水面はまだない．

## 静水を保つ計算

`balanced=1` では `h_a=f_a−fH,a` を場 `f_a` に保存する．
静水状態が方程式を満たすことから，厳密に

```
∂t h_a + div(c_a h_a) = (f_eq,a − f_a)/τ + S_a(f) − S_a(fH)
```

と書き換えられる．静水からの差を輸送するので，重力と圧力に別々の
打切り誤差が入らない．このように定常状態を保つ方法をwell-balanced法と呼ぶ．
既知の定常解からの差を使う考え方は
[Edelmannらの論文](https://arxiv.org/abs/2102.13111)の検討を参考にした．
そのEuler方程式のソルバーを移植したものではなく，上記の九方向の方程式を
本例で書き換えたものである．

`δρ=Σh_a`，`ρ=ρH+δρ`，`ρu=Σc_a h_a` として，衝突項も
`w_a[δρ+ρ(3c_a·u+9(c_a·u)²/2−3|u|²/2)]−h_a` から計算する．
これにより静水時の小さい数同士の差し引きを避ける．水平加速度を加える試験では，
その外力は基準静水解に含めず，全密度 `ρ` に作用させる．
基準解を各ステップで状態に上書きする処理や，分布の負値の切り詰めはない．

`balanced=0` は，同じ格子・壁・時間積分で全分布を直接輸送し，重力を足す対照実験である．
また静水に密度の乱れを与えて実際に流れが生じること，水平加速度による総運動量の
変化が `Px(t)=M×0.001×t` に一致することを検査する．静止することだけを合格条件にしない．

## 座標と壁

物理領域は `0≤X,Y≤2π`．左右は周期的，上下は水平な反射壁とする．
計算座標 `ξ,η` から物理座標への写像は

```
X = ξ + warpX sin ξ sin η
Y = η + warpY sin ξ sin η
```

で，直交格子は `(warpX,warpY)=(0,0)`，曲がった格子は `(0.2,0.15)` である．
両方の格子で同じ物理的な領域と壁になる．セルは写した四隅を直線で結んだ四辺形で，
面の法線と長さを端点から，面積を同じ四辺形から求める．
セル内の座標は，二つの計算座標それぞれに一次な双一次写像で表す．
セル平均の `ρH` と初期の乱れは，セル内の四点の値を重み付きで足すGauss積分で近似する．
保存する静水解はこの近似セル平均である．格子を変えても物理的な速度方向と外力の式は変えない．

Formuraの `mirror` は配列値の折返しであり，D2Q9の速度番号を反射させない．
本例では数値流束を作る際に，壁へ向かう分布を `(cx,cy)→(cx,−cy)` へ反射させる．
これを鏡面反射と呼ぶ．壁の法線方向には流れず，接線方向には滑る壁である．
粘性流体のすべりなし条件や，斜面の海底への一般化は別途検証する．

上下に一行ずつ補助セルを置き，両方の壁の面を配列内に確保する．
物理セルは `N×N`，記憶するセルは `N×(N+2)`，`ξ=x+hx/2`，`η=y−hy/2` である．
補助セルは物理量の積算から除外し，壁の流束は流体側の分布だけから決める．
処理系が用意する領域外のセルは `fixed 0.0` とし，そこでの座標値には依存しない．

内部ではMUSCL法（制限したセル内の傾きから面の値を求める方法）を用いる．
両隣の差から傾きの増大や符号反転を抑えるMC傾き制限を組み合わせる．
壁に接したセルの上下方向は一定値として再構成するため，壁付近の空間精度は一次である．
この境界処理について二次の収束を主張しない．格子細分化による乱れの投影値の変化も確認する．

## 検証と再現

```
python3 examples/kinetic_hydrostatic/run.py
# 保存したCSVの再検査（ビルド・流体計算なし）
python3 examples/kinetic_hydrostatic/run.py --reuse-results
```

既定では，16・32・64セル，二種類の座標で，静水・対照実験・密度の乱れを計算する．
乱れの初期密度は `ρH[1+0.001 cos X cos Y]`，初速はゼロである．
32セルでは静水の長時間試験，64セルでは時間刻み半減と水平加速度の試験を追加する．
計24条件．通常は `t=2π`，長時間試験は `t=8π` まで進める．

各更新で質量，流速，密度の変化，壁を通る質量と接線運動量の流量，
衝突と外力のモーメント，物理的な分布と平衡分布の最小値を出力する．
`densityMode` は，密度の変化を初期の空間的な波形 `cos X cos Y` と掛け合わせて
面積で平均した投影値である．図ではこの値を初期値で割り，乱れの伝播を比較する．
参照する解析解がある試験とは区別し，この量の格子間・時間刻み間の差を調べる．
分布の検査には，SSPRK2で平均する前の両Euler候補も含める．
差 `h_a` 自体は負になり得るので，非負性の対象は常に `fH,a+h_a` とする．
外力と静水からの差を含む本例に，前の輸送・衝突だけの非負性の十分条件をそのまま適用しない．
ここでは実測した非負性を検査し，一般の状態での保証は今後の課題とする．

2026-09-18の24条件はすべて通過した．静水からの差を使う場合は，全格子・
長時間試験とも最大流速と静水密度の変化が0だった．全条件で質量の相対変化は
最大3.265e-14，壁の質量流量は最大4.164e-17，水平加速度の総運動量誤差は
最大1.396e-16だった．物理的な分布とEuler候補を重みで割った最小値は0.8136以上で，
平衡分布も非負だった．

| 格子 | 16セル：通常の重力項の最大流速 | 32セル | 64セル |
|---|---:|---:|---:|
| 直交 | 2.018e-3 | 1.003e-3 | 5.004e-4 |
| 曲がった格子 | 2.300e-3 | 1.151e-3 | 5.751e-4 |

密度の乱れの最終投影値について，16→32セルの変化は直交格子で4.635e-6，
曲がった格子で4.983e-6，32→64セルではそれぞれ5.962e-7，6.500e-7へ減少した．
64セルで両座標の投影値の差は4.245e-9，時間刻みを半減した際の変化は
両座標とも8.927e-10以下だった．これは選んだ投影値での比較であり，
任意の格子での誤差や，壁付近の二次精度を保証するものではない．

`driver.c` は設定の受渡し，生成ソルバーの呼出し，診断値の出力だけを担う．
`run.py` はビルド・起動・結果の検査を担う．物理量の算出はすべてFME側で行う．
この例は，巻き込む波への重力・境界処理の組込みに先立つ基準試験である．
水面，海底の傾斜，水際の後退，波の動画への組込みは次の段階である．
