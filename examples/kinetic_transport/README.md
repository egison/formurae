# D2Q9の質量輸送と，水を表す割合の結合

`surface_transport` では流れをあらかじめ指定した．本例ではD2Q9（二次元で九方向の
速度分布を使う流体モデル）で密度と流れを計算し，その計算で面を通過する質量を使って
水を表す領域も移動させる．流れは時間とともに変化する．

**自由表面を作るための輸送の検証である．現在は全セルに同じ流体があり，その一部に
水という印を付けて運ぶ．印の外側も流体を計算しており，空気や真空ではない．**
印の境界に大気圧を与える処理，重力，新しく水になるセルの分布の初期化は次の段階である．
この区別を動画にも示す．

## 方程式と共有する流束

物理空間での方程式は次のとおりである．

```
∂t f_a + div(c_a f_a) = (f_a^eq − f_a)/τ
ρ = Σ_a f_a,   ρ u = Σ_a c_a f_a
∂t m + div(ρ u α) = 0,   m = ρ α
```

`f_a` は各方向の速度分布，`c_a` は固定した物理空間の基底に対する速度，
`ρ` は密度，`u` は流速，`α` は水の印の割合，`m` はその単位面積当たりの質量である．
平衡分布 `f_a^eq` は密度と運動量を保存する通常の二次の多項式を使い，緩和時間は
`τ=0.01` とする．印によって密度・粘性・平衡分布を切り替えない．
二次元の質量は，奥行きを単位長さとした質量に相当する．

計算では，各面を通る分布の流束 `F_a` を一度求める．流束は単位時間当たりに面を
通過する量である．その和 `Fρ=Σ_a F_a` が，実際に密度を更新する質量流束である．
水の流束には，同じ `Fρ` と，上流側から再構成した割合 `α_face` の積を使う．

```
ρ^E = ρ − Δt / A × Σ_faces Fρ,out
m^E = m − Δt / A × Σ_faces (Fρ,out α_face)
```

ここで `A` はセルの物理的な面積であり，上式の流束は面全体で積分した量である．
ソースの `B` と `massFlux` は計算座標の面長さで割った密度として保持し，
`∂_i` と `volumeCell` の組合せで同じ式を表す．
隣接セルは同じ面の値を逆符号で使うので，周期境界では全流体の質量と印の質量が保存する．
衝突項の密度・運動量の和はゼロである．

**密度が変わる場合に保存するのは `Σ A ρ α` である．** `Σ A α` は圧縮・膨張によって
変わり得るので，水量の保存検査に流用しない．また，セル中心の流速を別に補間したり，
`α` を独立な保存則 `∂t α+div(uα)=0` で運んだりすると，密度の更新との一致が失われる．
本例では分布から求めた面の質量流束をそのまま共有する．

時間積分はSSPRK2（二つのEuler更新を組み合わせる二次精度の方法）である．
各段で流束と密度を計算し直し，分布 `f_a` と質量 `m` を同じ段で更新する．
最後に平均するのも保存量の `f_a,m` であり，割合同士を直接平均しない．
表示用の `fraction` も常に更新後の `m/ρ` から求める．

## 0〜1を保つ十分条件

MUSCL法（セル内を傾きを制限した直線で近似する方法）で `α` を再構成する．
各セルの四つの面の値は0〜1にあり，その和は `4α` になる．
外向きの面流束を `Fρ,e` とし，`λ_e=Δt max(Fρ,e,0)/(Aρ)` とおく．
**全ての面について `4λ_e≤1`** なら，流出後に残る印の質量は

```
Aρ [α − Σ_e λ_e α_e] = Aρ Σ_e (1/4 − λ_e) α_e ≥ 0
```

となる．他のセルから入る印の質量も非負である．同じ議論が補集合 `1−α` にも適用でき，
密度の更新に同じ流束を使うことから `0≤m^E≤ρ^E` となる．
SSPRK2の最後の平均もこの関係を保つ．これは実数演算での十分条件であり，
浮動小数点の丸め誤差の厳密な上限を与えるものではない．

分布についても，再構成した分布と平衡分布の非負性，および
`2 C_pop + Δt/τ < 1` を確認する．`C_pop` は各方向の分布について，セルから
流出する割合の総和の最大である．割合の条件 `fractionCourant` と分布の条件
`populationCourant` を毎段検査し，両Euler候補と最終値の極値を累積する．
負の値や1を超えた値の切り詰め，全体の質量を戻す補正は行わない．

## 座標と初期条件

物理領域は `[0,1]²`，両軸の境界は周期的である．直交格子に加え，
`X=x+0.06 sin(2πx)sin(2πy)`，`Y=y+0.045 sin(2πx)sin(2πy)` の曲線格子を使う．
物理的なセル面積と面の法線は写像した頂点から計算する．運動量を計算する添字 `p` は
固定した物理基底，発散を計算する添字 `i` は計算座標であり，混同しない．
格子を変えると幾何係数が変わり，流体の衝突式・質量の輸送式は変わらない．
任意の曲線座標に対する自動的な幾何生成や，回転する物理基底は本例の対象外である．

初期の密度・流速・割合は，物理的な四角形内の四点Gauss積分（正の重みを持つ数値積分）で
平均する．初期分布には平均した密度・流速の平衡分布を使う．これは分布自体を厳密に
セル平均した値ではなく，滑らかな初期場に対する二次精度の近似である．
初期の印の質量はこの密度と割合の積とする．

- 静止：`ρ=1,u=0`．波形の境界の割合が変わらないことを調べる．
- 一定割合：`α=0.37`．下記の密度・流れの変化の中でも割合が一定かを調べる．
- 平行移動：`ρ=1,u=(0.15,0)`，`α=0.5+0.3 sin(2πX)cos(2πY)`．
  `X` を `X−0.15t` に置き換えた解析解のセル平均と比較する．
- 変形：`ρ=1+0.08cos(2πX)`，`u=(0.12sin(2πX)cos(2πY),−0.12cos(2πX)sin(2πY))`．
  印の境界は `Y=0.5+0.1cos(2πX)`，初期の遷移幅は0.04である．
  この流速は初期値だけに指定する．その後はD2Q9の圧力・衝突・輸送で変化する．

## 再現と検査

```
make kinetic-transport-verify
make kinetic-transport-gallery
```

16²・32²・64²，二つの座標，静止・一定割合，時間刻みの半減，割合の一次風上法との
比較を含む20条件を検査する．分布の輸送は全条件でMUSCL法を使い，
一次風上の比較では割合の再構成だけを切り替える．
小規模な確認は `python3 examples/kinetic_transport/run.py --probe --grids 16` で行える．
正規化結果の再利用は `--reuse-normalized`，実行結果の再利用はさらに `--reuse-runs` を付ける．
再利用時にはソース・処理系・設定・生成物・出力のハッシュを確認する．

検査基準は，全流体・印の質量および運動量の絶対変化が `2e−11` 未満，
割合が `[-2e−12,1+2e−12]` 内，静止・一定割合の誤差が `5e−12` 未満である．
解析解に対する面積積分誤差 `ΣA|α−α_exact|` は各細分化で0.7倍未満，
64²で0.003未満，64²のMUSCL法は一次風上法の0.4倍未満を条件とする．

密度が変わる変形試験では厳密解を使っていない．座標間の
`ΣAρ α(1−α)` の差が，16²から64²で半分未満かつ0.01未満であることを調べる．
この量は中間の割合の広がりを測る比較用の指標で，物理的な混合ではない．
32²で時間刻みを半分にした同指標の差は `1e−4` 未満とする．
この比較だけで界面形状全体の収束を証明したとはしない．
一定割合・変形試験では，密度の最大または最小が初期の範囲から `1e−4` 以上変わることも
検査する．初期値の空間的な密度差だけで，密度が時間変化したという検査を通さない．

初期条件・更新式・参照解・診断量は全て `kinetic_transport.fme` に記述する．
通常の `.fme → Egison → FEIR → .fmr → Formura → C` の生成経路を使い，
処理系や構文を拡張しない．Cドライバは設定・呼び出し・出力のみ，Pythonは
ビルド・実行・検査値の比較・保存結果の描画のみを担う．
記録用ヘッダを付ける前後で，小さい格子の診断出力がバイト単位で一致することも確認する．

## 検証結果（2026-09-18）

20条件が通過した．解析解に対する割合の面積積分誤差は次のとおりである．

| 格子 | 直交格子 | 曲線格子 |
|---|---:|---:|
| 16² | 3.135583e-03 | 4.055083e-03 |
| 32² | 9.256817e-04 | 1.082847e-03 |
| 64² | 2.153441e-04 | 2.611358e-04 |

全流体の質量の相対変化は最大1.688e−14，印の質量は最大4.885e−15だった．
一定割合0.37の誤差は最大6.107e−15．全Euler候補を含む割合は0〜1.0000000000000215で，
固定した検査許容値2e−12以内だった．`fractionCourant` は最大0.04809，
`populationCourant` は最大0.6136，密度の二通りの更新の差は最大8.882e−16だった．

64²のMUSCL法の誤差は，一次風上法の直交格子で0.03919倍，曲線格子で0.03670倍だった．
変形の指標の座標間の差は，16²・32²・64²でそれぞれ0.001520，0.0004919，0.0002536へ
減った．32²で時間刻みを半分にした指標の差は最大1.774e−8だった．
初期密度の範囲からの変化を確認する追加検査も，保存済みの診断値で通過した．

生成物と20条件の時系列・検査結果は `results/verification.json` に記録した．
動画は64²の二つの座標の保存した場だけを描画する．記録した場は `.build/kinetic-transport/` に
置き，配布する動画・静止画・描画の記録は `results/` に置く．

## 背景

[Compatible Fluxes for van Leer Advection (1998)](https://www.sciencedirect.com/science/article/pii/S0021999198960703)
は，保存量を別々に輸送するとそれらの比に余分な極値が生じる問題と，一致した流束の必要性を
扱う．本例の四面を用いた十分条件は上に示したものであり，同論文のアルゴリズムを
そのまま実装したものではない．
