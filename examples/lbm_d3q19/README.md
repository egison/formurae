# 19成分を添字で記述する格子ボルツマン法

3次元空間で19種類の移動速度を使う D3Q19 モデルで，正弦波状の流速が粘性により減衰する様子を計算する．
格子ボルツマン法は，格子点間を移動する分布から流れを求める方法である．

```formurae
dimension 3
axes x, y, z
index a : 19
field f_a
```

`a` は1〜19の分布の成分番号である．未宣言の `i` は1〜3の空間方向を表す．
速度の表 `directions` は19×3成分，重み `weights` は19成分の定数テンソルとして定義する．
初期条件と時間更新の両方で同じ表を使い，格子ごとの定数配列は作らない．

```formurae
local rho = ones~a . f_a
local u_i = (directions~a_i . f_a) / rho
```

`.` は上下の同じ添字について和を取る縮約である．上の式で密度と3成分の流速が得られる．
平衡分布を求める `feq` と各方向への移動を表す `pullx` / `pully` / `pullz` の引数にも
`W_a`，`C_a`，`Q_a` のように添字を明示し，19成分のテンソルを受け取る．
`feq` の戻り値を既存の `f_a` と足し引きするときは，`(feq ...)_a` と添字を付ける．
関数内で局所的に使った添字と，呼び出し側の添字を対応させるためである．

## 格子間の移動

`c = -1, 0, +1` に対して，中心1階・2階差分を使う次の式は正確な1セルの移動になる．

```text
q(x-c h) = q - c h Dq + c² h² D²q / 2
```

`c²` により，移動速度が0の成分はその位置に残る．各座標方向の処理を
`local h_a`，`local p_a` に保存してから合成することで，斜め方向への移動も表す．
通常の `.fme → Egison → FEIR → .fmr → Formura → C` の経路で実行する．

## 実行と検証

```sh
make lbm_d3q19
```

64×4×4点，1,000ステップを計算する．緩和時間 `tau=0.8` に対する理論上の動粘性係数は
`ν=(tau−0.5)/3=0.1` である．振幅の減衰から求めた値との相対差が2%未満，
質量の相対変化が10⁻¹²未満，横方向の流速が10⁻¹⁰未満であることを検査する．
密度，運動量，流速，振幅測定用の場は `.fme` で計算し，Formuraの集約演算で和と最大値を求める．
Cの検査用プログラムは生成コードを呼び出し，その結果を理論値と比較する．

測定した動粘性係数は0.10010（理論値との相対差0.105%），質量の相対変化は8.70×10⁻¹⁴，
x・z方向の最大流速は9.99×10⁻¹⁶で，すべての検査に合格した．
