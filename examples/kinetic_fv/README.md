# D2Q9 の有限体積輸送

二次元の波に向けて，まず衝突項を除いた9方向の分布の輸送を検証する．
有限体積法とは，セル内の量の変化を，隣接セルと共有する面を通る流量で求める方法である．
物理的な9方向，座標の定義，数値的な輸送処理を分離し，直交格子と曲がった格子で
同じ更新式を使う．シミュレーションの計算は初期条件・幾何・時間積分・診断値を含めて
すべて `.fme` に記述し，通常の生成経路を使う．Formura本体やFormurae処理系の拡張は不要．

## 輸送の高精度化

一次風上法は，流れが来る側のセル平均をそのまま面の値に使う．
安定性の基準になるが，分布をなだらかにする計算上の拡散が大きい．
今回追加するMUSCL法は，各セル内の分布を直線で近似し，その直線から面の値を求める方法である．
急な変化の近くでは傾きに制限をかける．
[有限体積法と高精度化の解説](https://www.clawpack.org/riemann_book/html/Approximate_solvers.html#High-resolution-methods)を参照．

計算座標の一方向について，セル平均を `q`，両隣を `q_left, q_right` とすると，
`back = q − q_left`，`forward = q_right − q` とし，傾きは次で定める．

```text
slope = minmod((back + forward)/2, 2 minmod(back, forward))
```

`minmod` は，2つの値の符号が違えば0，同じなら絶対値の小さい方を返す．
この選択はMC（monotonized-central）制限と呼ばれる．
セルの小さい／大きい計算座標側の面の値は `q − slope/2`／`q + slope/2` になる．
二方向それぞれに同じ制限を使う．滑らかな場所では二次精度を狙い，急な変化や極値では
傾きを抑えるため，最大誤差の実測次数が2を下回ることがある．

`sampleLower`／`sampleUpper` は，面の両側の値を直接選ぶ．
最初に面を挟む差 `jump` を求め，その差をセルの両側から選んで傾きを計算する．
傾きから得た面の値に対して，従来と同じ共有面の流量を計算する．
微分式の組合せによる隣接値の復元は使わない．必要な近傍は各軸で最大2セル先までである．

## 時間積分と非負性

高精度法にはSSPRK2（二段のRunge–Kutta法）を使う．輸送の時間変化を `L(q)` とすると，

```text
v = q + dt L(q)
w = v + dt L(v)
q_next = (q + w)/2
```

各Euler更新が非負性を保つとき，最後の平均も非負性を保つ．
[SSP時間積分の解説](https://www.sspsite.org/)を参照．
中間状態は既存の `field` と `local` で保持する．

非負のセル平均から出発すれば，MC制限で再構成した各面の値は `0 ≤ q_face ≤ 2q` を満たす．
各セル・各分布に対して，

```text
C = dt × 外向き流量係数の和 / セル面積 ≤ 1/2
```

なら，Euler更新で出ていく量は元の量を超えず，入ってくる量も非負になる．
これは今回使う十分条件であり，単に面の値を非負にするだけでは足りない．
一次風上法の十分条件は `C ≤ 1`．コードはどちらも同じ時間刻みを使い，各セルのCを計測する．

最小値・最大値は，保存した状態だけでなく `v` と平均前の `w` も含めて全更新で記録する．
最終値の切り詰めは行わない．一様分布を保つ面の幾何係数の条件の下では，
同じ制限は初期の最大値を超えることも抑える．
この検証は輸送部分についてのもので，衝突・重力・水面を加えた後は改めて確認する．

## 座標と保存量

物理座標を `X = x + ax sin(x) sin(y)`，`Y = y + ay sin(x) sin(y)` とする．
`ax = ay = 0` の直交格子と，`ax = 0.2, ay = 0.15` の曲がった格子で
同じ `transport` を使う．周期領域は `[0, 2π) × [0, 2π)`．
セルは座標写像で得た四頂点を直線で結ぶ四角形とし，`f_a` は物理空間のセル平均とする．
保存するセル内の量は `A f_a`（Aはセル面積）である．

`volumeCell = A/(hx hy)` を使う．物理速度を `(cx,cy)` とすると，
x方向の面の係数は `(ΔY cx − ΔX cy)/hy`，
y方向の面の係数は `(ΔX cy − ΔY cx)/hx` である．
差分はその面の両端点の物理座標から取る．係数を `B` として流量は

```text
F = max(B,0) f_lower + min(B,0) f_upper
```

となる．面に保存した流量の `∂_i` は，共有面の流量の差を刻みで割る．
`f_next = f − dt (∂_i F^i)/volumeCell` により，隣接セル間で量を保存する．
一様な分布を保つために必要な，面の係数の差の和の誤差を `closure` で記録する．

## 初期条件と参照値

一様分布，滑らかな分布，ゼロを含む急な分布を使う．
滑らかな分布は，物理空間の `1 + 0.2 cos(X + 2Y)` が各速度に沿って移動する問題である．
セル平均には，四頂点の双一次写像（各座標について一次の補間）上で，
2×2点のGauss積分（重み付きの四点評価）を使う．面積の重みも同じ写像の面積変換係数から求める．
初期値・移動後の参照値ともに滑らかな関数に対して四次精度の近似となるため，
今回の二次精度の検証で参照値の誤差が主成分になることを避ける．
時間に依存しない正弦・余弦のセル平均を `static field` に保存して計算を共有する．

急な分布は，写像したセル中央で `cos(X+2Y) > 0` なら1，それ以外は0として初期化する．
この場合は保存・非負性と分布のぼけを検査し，移動の厳密なセル平均との誤差は計測しない．
`error`／`errorL1` は0を出力する．

## 比較と診断値

| 設定 | 空間の更新 | 時間積分 | 目的 |
|---|---|---|---|
| `method = 0` | 一次風上法 | 前進Euler法 | 従来の基準 |
| `method = 1` | 中心的な流量 | 前進Euler法 | 急な分布で負値が出る比較 |
| `method = 2` | MC制限付きMUSCL法 | SSPRK2 | 高精度化する方法 |
| `method = 3` | 一次風上法 | SSPRK2 | 時間積分だけを変えた対照実験 |

`method = 0, 2` は三つの分布，`method = 1` は急な分布，`method = 3` は滑らかな分布で比較する．
格子サイズは16×16，32×32，64×64で，二種類の座標と合わせて48条件になる．
全条件の終了時刻は `t = 0.2π` とし，高精度法だけ計算時間が短くなる比較は行わない．

- `m1`〜`m9`：方向別の総量を領域面積で割った値．
- `error`：重みで割った分布の最大絶対誤差．
- `errorL1`：同じ絶対誤差の物理面積・9方向にわたる平均．
- `lowest`／`highest`：Euler候補を含む，全更新中の重みで割った分布の最小値・最大値．
- `mixing`：`q=f_a/weight_a` とした `q(1−q)` の物理面積・9方向にわたる平均．
  急な0/1分布で，中間の値へどれだけ広がったかを調べる．初期値は0で，ぼけると増える．
  水面の厚さを測る値ではない．滑らかな分布の場合は判定に使わない．
- `cfl`：上記の時間刻みの係数Cの最大値．
- `closure`：一様分布を保つための，面の幾何係数の差の和の最大絶対値．
- `minArea`：最小セル面積．

## 測定結果（2026-09-17）

全48条件の検査が通った．滑らかな移動問題の64×64セルでの結果は次のとおり．
誤差は重みで割った分布について測る．

| 座標 | 一次風上法＋Eulerの最大誤差 | MUSCL＋SSPRK2の最大誤差 | MUSCLの平均誤差 | 最大／平均誤差の収束次数（32→64） |
|---|---:|---:|---:|---:|
| 直交 | 0.02798 | 0.003788 | 0.0008247 | 1.52 / 1.82 |
| 曲がった格子 | 0.03542 | 0.005460 | 0.0008616 | 1.51 / 1.82 |

時間積分だけをSSPRK2に変更した一次風上法との比較でも，最大誤差は
直交格子で約7.52分の1，曲がった格子で約6.57分の1になった．
次数2への到達を最大誤差で主張せず，傾きの制限を含む上記の実測次数を報告する．

急な分布の64×64セルでの `mixing` は，直交格子で0.06989から0.03050，
曲がった格子で0.07201から0.03189へ低下した（一次風上法＋Eulerとの比較）．
中間値への広がりは両格子で55%以上減ったが，これは水面を結合する前の輸送試験である．

新しい方法は全条件で負値を作らず，負値を出す対照実験を除く42条件は
初期の最小・最大値の範囲を丸め誤差の範囲内で維持した．
全48条件での方向別総量の相対変化は最大4.67×10⁻¹⁴，
一様分布の最大誤差は7.78×10⁻¹⁶未満だった．
時間刻みの係数Cの最大値は約0.244で，非負性の十分条件1/2以内である．

## 実行とギャラリー

```sh
make kinetic-fv-verify
make kinetic-fv-gallery
```

`--grids 16` で小さい試験だけを実行できる．
`--reuse-normalized` はFMEと処理系の識別情報が一致する場合だけ正規化結果を再利用する．
全更新の診断値は `.build/kinetic-fv/grid-*/` のCSV，検証結果と処理系の識別情報は
`results/verification.json` に保存する．CSVの `update` は生成された更新の番号で，
SSPRK2では2更新が物理的な1ステップになる．誤差は完了した物理ステップで更新する．

Pythonはビルド・設定・結果の入出力と記録した診断値の検査を担当する．
Cドライバは設定値の受渡し・生成ソルバーの呼出し・出力だけを担当し，数値積分は行わない．
保存済みの診断値から図を描き，日英の波の専用ページ `waves.html#kinetic-fv` を更新する．
Matplotlibを別環境で使う場合は `PLOT_PYTHON=/path/to/python` を指定する．

今回も周期境界・衝突なしの輸送を扱う．波への結合では衝突項と粘性，重力と静水のつり合い，
壁，水面と水際の更新を順に検証する．MPI実行とこの高精度法の時間方向のブロッキングは未検証．
