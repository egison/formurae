# D2Q9 の有限体積輸送

二次元の波に向けて，まず衝突項を除いた9方向の分布の輸送を検証する．
有限体積法とは，セル内の量の変化を，隣接セルと共有する面を通る流量で求める方法である．

## 固定する設計

- `f_a` は物理空間のセル平均．保存するセル内の量は `area * f_a`．
  9方向の速度は物理空間に固定し，格子の添字方向とは区別する．
- セルは座標写像で得た四頂点を直線で結ぶ四角形．面の向きと長さ，
  セル面積は同じ四頂点から定める．連続座標写像の点ごとの体積要素を
  セル面積の代わりに使わない．
- 共有面の流量を一度定め，両側のセルには逆符号で加える．
  最初は一次精度の風上法（流れが来る側のセル平均を使う方法）と前進Euler法．
- 物理モデル，格子形状，面の流量を計算する数値手法を分ける．
  座標に依存しない物理モデルを維持する一方，数値手法には配置情報を明示する．
- `sampleLower(f,1,0)` と `sampleUpper(f,1,0)` は，整数点にある `f` を
  x方向の半整数点の面へ持ってくる際，小さい／大きい計算座標側の値を選ぶ．
  補間や微分は行わない．対象式全体を選んだ元の位置で評価する．
  元と先の配置がちょうど1軸で異なることを要求する．
  配置を持たない定数だけの式，同じ配置，2軸以上の同時変更はエラー．
  `resample` は従来どおり線形補間であり，意味を混ぜない．
- 時間刻みは各セル・各速度について「時間刻み × 外向き流量係数の和 / 面積 ≤ 1」
  を満たすようにする．正の初期値から負値を作らないことを毎ステップ記録する．
  後からBGK衝突（局所平衡へ近づける処理）を同時に加える場合は，
  この係数に `dt/tau` を加えた条件と，平衡分布の非負性が別途必要．
- 最初は周期境界．壁・重力・水面は輸送の検証後に追加する．
  空気と水の界面を含む砕波そのものの検証とは区別する．

## 検証項目

一様分布，滑らかな分布，ゼロを含む急な分布を扱う．各方向の総量，
全ステップ中の最小値，時間刻みの条件，格子を細かくしたときの誤差を確認する．
従来の中心差分の実験は `../kinetic_coordinates/` に保持する．

`sampleLower` / `sampleUpper` は Formurae の数式から，既存の Formura の
直接配列参照に変換する．Formura 本体の変更は不要である．初期条件・形状・
時間積分・診断を含むシミュレーション計算はすべて `.fme` に記述する．

## 座標と更新式

物理座標を `X = x + ax sin(x) sin(y)`，`Y = y + ay sin(x) sin(y)` とする．
`ax = ay = 0` の直交格子と，`ax = 0.2, ay = 0.15` の曲がった格子で
同じ `transport` を使う．両方の物理座標が両方の計算座標に依存する．
周期領域はどちらも `[0, 2π) × [0, 2π)` である．

セルの面積を `A`，計算座標の刻みを `hx, hy` とし，
`volumeCell = A/(hx hy)` を使う．物理速度を `(cx,cy)` とすると，
x方向の面の係数は `(ΔY cx − ΔX cy)/hy`，
y方向の面の係数は `(ΔX cy − ΔY cx)/hx` である．
ここで差分はその面の**両端点の物理座標**から取る．
この係数を `B` として，一次風上流量は
`F = max(B,0) f_lower + min(B,0) f_upper` となる．
コード内の対称な式はこれと同値で，`method = 1` のときだけ中心的な流量になる．

面に保存した流量の `∂_i` は，隣接する共有面の流量の差を刻みで割る．
したがって `f' = f − dt (∂_i F^i)/volumeCell` は，
セル内の量 `A f` に対する有限体積更新である．
一様な分布が保たれるためには面の係数の差の和がゼロになる必要があり，
`closure` がこの誤差を記録する．

`f` はセル平均として更新する．滑らかな初期条件と移動の参照値には，
写像したセル中央で評価する中点近似を使う．これは厳密なセル積分ではなく
格子幅の二乗の誤差を含む．今回調べる一次精度の輸送誤差より高い精度である．
急な分布には同じ中央値による0/1の初期化を使い，保存と非負性を確認する．
不連続な分布の厳密なセル平均や収束次数の検証は今回の範囲に含めない．
急な分布の場合の `error` 列は初期分布との差であり，移動の精度の判定には使わない．

## 実行と記録

```sh
python3 examples/kinetic_fv/run.py
```

既定は16×16，32×32，64×64セル．各格子で，二種類の座標，三種類の初期分布，
風上法を検証し，急な分布について中心的な流量も比較する．
格子数と同じ回数更新するので，すべて同じ時刻 `t = 0.2π` まで計算する．
全ステップの診断値は `.build/kinetic-fv/grid-*/` のCSV，
検証結果と処理系の識別情報は `results/verification.json` に保存する．
`--grids 16` で小さい試験だけを実行できる．
`--reuse-normalized` はFMEと処理系の識別情報が一致する場合だけ正規化結果を再利用する．
Pythonはビルド・設定・結果の入出力と記録した診断値の検査，Cドライバは設定値の受渡し・
生成ソルバーの呼出し・出力を担当する．状態更新や幾何・診断値の計算は行わない．

## 測定結果（2026-09-17）

24条件すべてが検査を通過した．風上法の全ステップ・全方向で分布の最小値は
0以上で，急な初期分布でも負値は発生しなかった．各方向の総量の相対変化は
全24条件を通して最大 `4.67e-14`，一様分布の最大誤差は `7.78e-16` だった．
面の幾何係数の差の和の誤差は最大 `2.04e-14`．
時間刻みの条件の左辺は最大 `0.244` で，非負性の条件である1以下を満たす．

| 格子 | 直交格子の誤差 | 曲がった格子の誤差 |
|---|---:|---:|
| 16×16 | 0.09030 | 0.10430 |
| 32×32 | 0.05187 | 0.06381 |
| 64×64 | 0.02803 | 0.03559 |

誤差は滑らかな移動問題の `max |f_a/w_a − reference_a/w_a|`．
32→64セルの実測次数は直交格子0.888，曲がった格子0.842で，
一次精度へ近づく傾向を確認した．格子を増やしても形を鋭く保てる高精度法は
次の課題である．今回の風上法は基準として単純で，数値的な拡散が大きい．

比較用の中心的な流量と前進Euler法では，64×64セルの急な分布の最小値が，
直交格子で−0.753，曲がった格子で−1.084になった．
これは今回の比較条件での結果であり，過去の中心差分＋三段の時間積分の結果とは
同一視しない．分布の値の切り詰めは行っていない．

処理系の検査では，隣接値の選択を生成Cで実行し，座標係数の評価位置，
9成分，周期境界，時間方向のブロッキングも確認した．
この輸送実験では通常の単一プロセス計算を使った．
衝突項・壁・重力・水面との結合，MPI実行は引き続き検証する．
