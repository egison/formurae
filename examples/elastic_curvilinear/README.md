# 円筒座標・球座標の弾性波

`elastic_cylindrical` と `elastic_spherical` は，同じ三つの関数 `strain`，
`stressRate`，`stressDiv` から生成する三次元の速度・応力ソルバーである．
速度の3成分と対称応力の6成分を同じ格子点に置く．
座標に依存する係数は計量からEgisonで計算し，流束全体の差分をFormuraeで生成する．

## 再現

Formuraeのルートで次を実行する．Haskellのビルドと検証はすべて直列に行う．

```sh
python3 tools/validate_curvilinear_elastic.py
```

Pythonは標準ライブラリだけを使う．`cc`，Cabal/GHC，`bin/formura` が必要である．
`tools/prepare_elastic_validation.sh` は隣のEgisonリポジトリから
`1a0298c67cc487dd4a73d96f526f3042b74d6570`（2026-07-28）を
`.build/egison-elastic-validation` に展開する．Egisonの作業ツリーは変更しない．
この版はFormuraeの現行スナップショットと同時期のものである．
2026-09-07時点のEgison HEADでは型記法と型検査が変更されており，
新しい例だけでなく既存の `diffusion1d` もそのままでは正規化できない．
依存先の移行と数値実験の再現を混同しないため，この実験では版を固定している．
初回のCabalビルドは通常のキャッシュとログへの書き込みを伴う．

個別の例は次で実行する．

```sh
EGISON_DIR=$(tools/prepare_elastic_validation.sh)
make elastic_cylindrical EGISON_DIR="$EGISON_DIR"
make elastic_spherical EGISON_DIR="$EGISON_DIR"
examples/elastic_cylindrical/check stability
examples/elastic_spherical/check stability
```

結果は `results/validation.json` と収束表に保存する．
格子幅・時間刻みごとの生成C，検証実行ファイル，詳細ログは `.build/` に置く．
`.fme` のゼロ初期値は記憶域の初期化であり，検証ドライバが各実験の
解析解または全成分を励起する初期値を設定してから生成カーネルを実行する．

## 数式と格子上での評価

時間に依存しない計量を $g_{ij}$，逆計量を $g^{ij}$，
体積係数を $J=\sqrt{\det g}$ とする．同じ上下添字について和を取る．
物理的な半径は $R=1+r$，球座標の余緯度は $T=1+\theta$ である．

- 円筒座標：$g=\operatorname{diag}(1,R^2,1)$，$J=R$．
  領域は $R\in[1,2]$，$\theta\in[0,2\pi)$，$z\in[0,1]$．
- 球座標：$g=\operatorname{diag}(1,R^2,R^2\sin^2T)$，$J=R^2\sin T$．
  領域は $R\in[1,2]$，$T\in[1,\pi-1]$，$\phi\in[0,2\pi)$．

共変微分とは，座標の基底の変化を含めた微分である．
対称化した共変微分によるひずみ速度と応力の発散を，計量を使って書く．

$$e_{ij}(v)=\frac12\left(g_{ik}D_jv^k+g_{jk}D_iv^k+
  (\partial_k g_{ij})v^k\right),$$

$$(\mathcal D\sigma)^i=\frac{g^{ik}}J D_j(Jg_{k\ell}\sigma^{\ell j})
  -\frac12 g^{ik}(\partial_k g_{j\ell})\sigma^{j\ell}.$$

ここで $\partial_k g_{ij}$ はEgisonが解析的に計算し，$D_j$ は格子上の差分である．
$D$ を通常の微分に置き換えると，後者は $\nabla_j\sigma^{ij}$ に一致する．
この等価な保存形は，離散化したあとにもエネルギー収支を保つために使う．
流束の $J$ と $g$ は**参照先の格子点**で評価し，外側の $g^{ik}/J$ は
**更新対象の格子点**で評価する．補正項の全成分は同じ格子点にあるため補間を要しない．
流束に積の微分則を適用してから各項を差分化する操作とは異なる．

構成則は $\mathcal C(e)^{ij}=\lambda g^{ij}g^{k\ell}e_{k\ell}
+2\mu g^{ik}g^{j\ell}e_{k\ell}$ であり，$\lambda=2,\mu=\rho_0=1$ とする．
中間の `local` 配列に力，半時間刻みの速度，ひずみ，応力の変化率を格納する．
これにより球座標の大きな有理式を一度に正規化する必要がなくなる．
これらは既存のユーザー定義関数・配列機構を使い，コンパイラには弾性波専用の演算子を追加しない．

## 境界とエネルギー

半径方向の両壁では速度の全成分を0に固定する．
円筒の軸方向の両端，球の余緯度方向の両壁では，壁に垂直な速度と
接線方向の表面力を0にする滑り壁を使う．角度の残る一方向は周期的である．
どの壁でも応力による仕事は0になる．

有界方向には **summation by parts（SBP，部分積分に対応する離散恒等式）**を
満たす同一点配置の差分を追加した．内部では中心差分，両端では前進・後退差分を使う．
$H=h\operatorname{diag}(1/2,1,\ldots,1,1/2)$ に対し
$HD+D^TH=\operatorname{diag}(-1,0,\ldots,0,1)$ となる．
流束の差分にも速度の差分にも同じ行を使う．
YAMLの `fixed 0.0` はFormuraの原点が移動しない実行経路を選ぶためにも必要である．
SBPの境界行は領域内だけを参照し，壁の物理条件はFME内の成分別マスクで与える．

時間積分は速度Verlet法（速度を半刻み，応力を一刻み，速度を半刻み進める2次の方法）である．
$A\sigma=\mathcal D\sigma/\rho_0$，$Bv=\mathcal C(e(v))$ とする．
速度のエネルギー内積を表す行列を $M_v$，応力の内積を表す行列を $M_s$ とすると，
SBPと境界条件から $M_vA+B^TM_s=0$ が成り立つ．
したがって，半離散系では

$$E=\tfrac12v^TM_vv+\tfrac12\sigma^TM_s\sigma$$

が保存される．Verlet法では

$$\widetilde E=E-\frac{\Delta t^2}{8}(A\sigma)^TM_v(A\sigma)$$

が丸め誤差を除いて保存される．
$\Delta t\|M_v^{1/2}AM_s^{-1/2}\|_2<2$ ならこの二次形式は正であり，安定性を与える．
この条件は時間刻みに制約を課す．実験は $\Delta t=0.05\Delta r$ とその時間精度検査用の変更で行う．
通常の $E$ と時間積分に対応する $\widetilde E$ を別々に記録する．

## 検証の構成

1. **独立な全成分の参照計算**：ドライバ内で，計量の具体式，SBP境界行，
   ひずみ，発散，Verlet更新をCで独立に実装する．生成コードの最初のステップを
   全格子点・全9成分で照合する．
2. **解析解との収束**：両半径壁で0となるねじれ振動を使う．円筒では
   $f(R)=J_1(kR)Y_1(k)-Y_1(kR)J_1(k)$，球では同式のBessel関数を
   球Bessel関数に替える．$f(2)=0$ の最小の正根を二分法で求める．
   円筒の座標成分は $v^\theta=f(R)\cos(kt)/R$，球では
   $v^\phi=f(R)\cos(kt)/R$ である．対応するせん断応力を解析式から計算する．
   半径を16，32，64区間に分け，1周期後の速度と応力のエネルギーノルム誤差を測る．
   この試験では他方向の解の座標成分は一定であり，その格子数は固定する．
3. **時間精度**：空間格子を固定し，同じ初期値を $t=0.2$ まで刻み幅を半減して進める．
   隣り合う刻み幅での全成分の差のノルムを求め，その比から収束次数を測る．
   最も細かい時間積分を共通の参照にした差も併記するが，有限な参照の誤差の影響を
   避けるため，時間次数の主な指標は前者とする．
4. **全方向の座標変換の検査**：デカルト座標のアフィン速度 $v(X)=AX+b$ と
   一様応力 $\sigma(X,t)=S+t[\lambda\operatorname{tr}(A)I+\mu(A+A^T)]$ を
   各座標系へ変換する．全方向の格子幅を半減し，1ステップの誤差を時間刻みで割った
   変化率の誤差を測る．これは全成分を使う内部の打切り誤差の検査であり，
   壁から4点以内を除外する．壁を含む解析解の精度は上記のねじれ振動で検査する．
5. **長時間の安定性**：全方向に変化する速度3成分・応力6成分を初期化し，
   1万ステップ進める．通常のエネルギーの最大・最小と，$\widetilde E$ の相対変化を
   初回，50ステップごと，最終ステップに検査する．

`results/validation.json` は各基準の合否を含む．座標変換の内部検査は初期値が
壁条件を満たさないため，全領域のエネルギー保存を合否に使わない．
長時間検査とねじれ振動は壁条件を満たす初期値で独立に行う．

## 実測結果（2026-09-07）

全22回の数値実行と収束次数の検査が通過した．両モデルの三つの `def` の
定義行が完全に同一であることも再現スクリプトが検査する．

| 半径の区間数 | 円筒：固有モードの相対誤差 | 球：固有モードの相対誤差 |
|---:|---:|---:|
| 16 | 4.07985e-2 | 3.97213e-2 |
| 32 | 1.01078e-2 | 9.76630e-3 |
| 64 | 2.52217e-3 | 2.43761e-3 |
| 観測された次数 | 2.013，2.003 | 2.024，2.002 |

1周期に達する最初のステップで，その実際の時刻の解析解と比較した．
格子を細かくするたびに誤差がおよそ4分の1になる．

| 各軸の区間数 | 円筒：全方向の内部変化率誤差 | 球：全方向の内部変化率誤差 |
|---:|---:|---:|
| 16 | 1.54566e-1 | 1.67871e-1 |
| 32 | 4.16005e-2 | 4.54566e-2 |

| 観測された次数 | 1.894，1.943 | 1.885，1.939 |

内部変化率誤差は物理成分の最大絶対差を時間刻みで割った値である．
周期方向の点数は区間数に等しく，有界方向には端点を含めて1点多く置く．

| 指標 | 円筒 | 球 |
|---|---:|---:|
| 時間収束次数（隣り合う解の差の比） | 2.000037，2.000009 | 2.000055，2.000014 |
| 1万ステップでの通常エネルギーの範囲 / 初期値 | [1，1.00002625964] | [1，1.00001653542] |
| 同じ試験の修正エネルギーの最大相対変化 | 6.98e-15 | 9.23e-15 |
| 独立参照との最大絶対差（全試験） | 2.22e-16 | 2.22e-16 |

長時間試験は $\Delta t=0.0015625$，$t=15.625$ まで行った．
エネルギーの範囲は上記の検査時点での値である．
円筒は $33\times16\times17$，球は $33\times17\times16$ 格子を使う．
計量と流束の評価位置が一致する独立参照照合，連続方程式の解析解への収束，
離散エネルギー恒等式に対応する保存量の検査が，異なる観点から生成コードを裏付ける．

[結果JSON](results/validation.json)には各実行の刻み幅，時刻，格子数，誤差，
保存量，合否，ソースのハッシュを保存している．
[関連研究との比較](RELATED-WORK.md)では，これらの結果を言語の記述性と
コード生成の観点から位置づける．

## 論文用の可視化データ

次のコマンドは，検証済みの `.fmr` から C を再生成し，円筒・球座標それぞれで
1万ステップのエネルギー時系列と，ねじれ振動の二つの位相での速度分布を記録する．
Formura と C のコンパイル，数値実行を直列に行い，Cabal/GHC の再ビルドは行わない．

```sh
python3 tools/collect_elastic_figure_data.py
```

出力は `results/figures/` に保存する．`records.json` にはソース・生成物のハッシュ，
実際の時刻，検証結果を含む．6回の追加実行はすべて検証を通過した．
通常・修正エネルギーの極値は上の長時間検証と一致した．

- `*-energy.dat` は初期状態，最初のステップ，以後50ステップごとの実測値であり，
  通常のエネルギーの相対変化と修正エネルギーの相対変化を別々に記録する．
- `*-profile-1.dat` と `*-profile-3.dat` は，周期の1/8と3/8以降の最初のステップでの
  半径方向の分布である．半径は32区間とし，円筒の `R*v^theta` と球の赤道の
  `R*sin(T)*v^phi` を使う．各行には生成コードの出力と実際の時刻での解析解を含む．

これらは既存の検証ドライバに出力だけを追加したものである．
ドライバの `FORMURAE_ELASTIC_TRACE` と `FORMURAE_ELASTIC_PROFILE` 環境変数で
それぞれの出力先を指定できる．数値更新と合否の基準は同じである．
