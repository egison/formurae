# 円筒・球面上のテンソル方程式のデモ

[日本語ギャラリー](../../html/ja/gallery.html#tensor-demos) / [English gallery](../../html/en/gallery.html#tensor-demos)

三つの応用を四本の詳細動画と，押す・ねじる・かき混ぜる三つの導入動画で示す．動画は生成された C コードによる時間発展の保存値から描画する．
全フレームでカメラ・色範囲を固定し，初期画像と最終画像の補間は行わない．
描画後には，時刻や説明を重ねる前の画像が解放後も変化していることと，
MP4/GIF のフレーム数・ファイルのハッシュを [動画の検証記録](results/animation-validation.json) で確認する．

まず [三つの操作の動画](../../html/ja/gallery.html#tensor-intro) で，動かした場所と，手を離した後の変化を見ることができる．

| 操作 | ソース | 表示 |
|---|---|---|
| ボールを押して離す | [press_ball.fme](press_ball.fme) | 押した場所を橙色で示し，へこみの回復と反対側への伝播を追う．変位は 8 倍． |
| 管をねじって離す | [twist_tube.fme](twist_tube.fme) | 下端を固定し，上端を回す．材料に描いた縦線のねじれを追う．変位は 6 倍． |
| 液体をかき混ぜて止める | [oldroyd_couette.fme](oldroyd_couette.fme) | 液体の目印を追い，内筒の停止後の逆回転を見る．移動量は実寸． |

[液体の導入動画](../../html/ja/gallery.html#recoil-intro) では，
内筒を回す，止める，液体が少し逆回転する，という変化を目印の動きで追える．
これは下記の粘弾性流体の同じ計算結果を別の方法で表示したものである．
保存した速度場を時間・空間で線形補間し，48 個の目印の軌跡を 4 次 Runge–Kutta 法で積分する．
移動量は拡大せず，全区間を約 1/2 倍速で表示する．矢印は流れの方向だけを示す．
`t=11…17.4` の最初の逆回転を取り上げ，内筒が `t=14` 以降停止したままであることと，
目印の時間刻みを半分にしたときの差を [記録](results/couette-recoil.json) に残す．
日本語動画の描画には Hiragino Sans または Noto Sans CJK JP などの日本語フォントを使う．

| 応用 | Formurae ソース | 動画で観察するもの |
|---|---|---|
| 異方性弾性体 | [円筒](anisotropic_cylinder.fme)，[球殻](anisotropic_sphere.fme) | 同じ初期速度に対する，等方的な材料と半径方向を補強した材料の振動の違い |
| 粘弾性 Taylor–Couette 流れ | [回転する円筒間の流体](oldroyd_couette.fme) | 高分子応力の輸送と変形，内筒を停止した後の流れと応力の緩和 |
| 球面のネマチック液晶 | [球面の配向テンソル](nematic_sphere.fme) | 分子の向きの緩和と，向きが定まらない点（欠陥）の移動 |

## 実行

Formurae の Cabal ビルド環境と `make setup` で用意した `bin/formura`，C コンパイラ，
隣接する Egison の Git リポジトリを使う．Egison は既存の
`tools/prepare_elastic_validation.sh` により検証用の固定コミットを展開する．
Python は 3.11 以降を使う．描画には画面外で描画できる VTK 環境が必要である．

```sh
python3 -m venv .build/tensor-demo-venv
.build/tensor-demo-venv/bin/pip install -r examples/tensor_demos/requirements.txt
make tensor-demos TENSOR_PYTHON=.build/tensor-demo-venv/bin/python
```

上の一つのコマンドが，検証，六条件のシミュレーション，MP4/GIF/PNG の生成を順番に行う．
途中から再開する場合は，`tensor-demo-checks`，`tensor-demo-simulate`，
`tensor-demo-render` を個別に実行できる．`make all` の従来の例題とは別のターゲットである．
生成された `.egi`，`.feir`，`.fmr` はこのディレクトリ，検証結果は `results/`，
動画は `gallery/tensor/`，C コード・共有ライブラリ・時系列データは `.build/tensor-demos/` に置く．
`results/*.json` は実行時のソースと生成 C の SHA-256 を記録する．

## 方程式と実装の分担

`g` は座標の長さと角度を表す計量，`∇` は基底の位置による変化も含む共変微分である．
上付き・下付き添字はそれぞれ反変・共変成分を表し，同じ文字の上・下添字を足し合わせる．
`.fme` の `def` がひずみ，応力の発散，テンソルの輸送，微分と縮約を定義する．
`{~i~j}` のような宣言は添字交換に対する対称性を指定する．
これらの演算子に固有の変換規則をコンパイラに追加していない．

粘弾性流体では，利用者は一つの `.fme` に方程式，初期値，物理パラメータ，
時間更新，境界値，各段階の実行順を記述する．`formurae run` が検査と C の生成・実行を行う．
汎用の C 実行部が配列の平均，境界の補助セルへの転送，Poisson 方程式の求解を行い，
Python は保存結果の描画に使う．[実行仕様](../../docs/native-execution.md)に詳細を記載した．

```sh
formurae run examples/tensor_demos/oldroyd_couette.fme
```

生成 C と実行ファイルは入力ファイルの隣の `oldroyd_couette.native/`，
保存配列と報告はその中の `output/` に置く．利用者が C や Python を書く必要はない．
ギャラリーの再現には `make couette-check`，`make couette-simulate`，
`make couette-render` を使う．最初の二つは Python を起動しない．
ギャラリー用の各段階の生成物は `generated/oldroyd_couette/` に保存する．
[従来の保存結果との比較](results/couette-native-regression.json)も記録した．

弾性体と液晶のデモは Formurae → Egison → Formura → C で空間演算を生成し，
Python が時間積分，境界値，球面の座標間のデータ交換を担当する．

### 押す・ねじる操作と解放

`press_ball.fme` と `twist_tube.fme` は，次節と同じ三次元の速度・対称応力の方程式を使う．
ここでは `λ=2, μ=1, ρ=1, α=0` とし，等方的な線形弾性体を扱う．
空間演算は生成 C コード，境界の操作と時間積分は `tools/tensor_demo_manipulation.py` が担当する．
動画の色は材料上の目印であり，応力や速度の色尺度を読む必要はない．

球殻は半径 1〜2 の全球で，最初は静止している．+x 方向を中心とする角半径 0.65 の外面の一部に，
法線方向の変位を与える．中心から離れるほど変位を小さくし，境界では滑らかにゼロにする．
中心の押し込み量は `0.035 s(t/1.5)`，`s(x)=10x³−15x⁴+6x⁵` である．
`t=1.5` で拘束を取り除き，その後は全表面を表面力ゼロとする．
押し具は法線変位を指定する理想化した拘束として扱う．半径方向 17 点，角度分割の基準 48，`t=9` まで計算する．
球の方位角 90 度分を切り除くのは表示だけであり，計算には内部・外部の全球面を含む．

管は半径 1〜2，長さ `2π` の有限の円筒である．下端の速度はゼロに固定する．
上端の回転角を `0.065 s(t/4)` とし，対応する接線速度を境界に与える．
`t=4` で上端を表面力ゼロに切り替え，下端は固定を保つ．内外の側面も表面力ゼロである．
半径 17 点，円周 48 点，軸方向 25 点で `t=22` まで計算する．この例の軸方向は周期境界ではない．

時間積分には 4 段の Runge–Kutta 法を使う．自由表面では，応力とその時間変化を
弾性エネルギーの内積について直交射影し，表面力をゼロにする．二つの自由表面が交わる端では
両方の条件を同時に解く．操作を解放するときの射影がエネルギーを増やさないことを検査する．
押す場所の指定変位は，座標間の補間後にも再適用する．解放時刻までの最後の段は操作中の境界条件で積分し，
その直後に拘束を解除する．この切り替えを含む時間刻みの細分化を
[時間精度の記録](results/manipulation-time-validation.json) で確認する．
管の検証には固定端・自由端のねじれ振動の解析解
`uθ=a r sin(kz) cos(kt), σθz=a k r cos(kz) cos(kt), k=1/4` を使う．
ここで成分は長さ 1 の直交基底での値であり，せん断波の速度は `sqrt(μ/ρ)=1` である．
解析解への空間収束，境界の拘束，有限性，解放後のエネルギー変動を
[検証記録](results/manipulation-validation.json)，[ボール](results/press-ball.json)，[管](results/twist-tube.json) に残す．

### 1．半径方向に補強した弾性体

速度 `v`，対称応力 `σ`，ひずみ速度 `e` の関係は

\[
 \rho\partial_t v^i=\nabla_j\sigma^{ij},\qquad
 e_{ij}=\tfrac12(\nabla_i v_j+\nabla_j v_i),
\]
\[
 \partial_t\sigma^{ij}
 =\lambda g^{ij}g^{kl}e_{kl}
  +2\mu g^{ik}g^{jl}e_{kl}
  +\alpha n^i n^j n^k n^l e_{kl}.
\]

`n` は半径方向の単位ベクトルである．`ρ=1, λ=2, μ=1` を固定し，
`α=0` と `α=6` を比べる．最後の項が半径方向の剛性を高めるため，
四階の弾性テンソルの全成分を列挙せずに異方性を加えられる．
`strain`，`stressRate`，`stressDiv` は円筒・球殻で同じ定義を使う．

半径は 1〜2，内外の面は表面力ゼロである．円筒の軸方向は長さ `2π` の周期境界で，
切断表示の上下端は自由端ではない．球殻は極を含む全球であり，後述の二つの座標を使う．
初期応力・変位はゼロ，初期速度は角度依存性を持つ滑らかな三成分の場である．
半径方向 17 点，角度分割の基準 48，4 次 Runge–Kutta 法，`dt=0.005`，`t=0…5`．
球面では各座標が 33×81 点，円筒では円周 48 点・軸方向 24 点になる．

動画は半分を切り除き，不透明な外面・内面・切断面の速度の大きさを着色する．
変位は形を読み取るために 8 倍で表示する．切り除く処理は描画だけに作用し，
切断面で反射する境界条件は追加しない．

検証では Cartesian 座標で与えた一次の速度場と一定の応力場を座標変換し，
生成演算と独立な成分実装・連続方程式の解析値を比較する．
半径方向の分割を 8→16→32 と増やして誤差の減少を測る．
動画の全保存時刻で表面力，有限性，運動エネルギーと弾性エネルギーの和を検査する．

### 2．粘弾性流体の回転と停止

Oldroyd-B モデルは，溶媒の粘性と，高分子の変形を記憶する対称テンソル `C` を組み合わせる．
`C` はすべての方向で正の伸びを表す正定値行列で，平衡値は逆計量 `g⁻¹` である．

\[
 \nabla_i v^i=0,\qquad
 \rho(\partial_t v^i+v^j\nabla_jv^i)
 =-\nabla^ip+\nabla_j[2\eta_s e^{ij}+\tau^{ij}],
 \quad \tau^{ij}=\frac{\eta_p}{\lambda_r}(C^{ij}-g^{ij}),
\]
\[
 \partial_t C^{ij}+v^k\nabla_kC^{ij}
 -C^{kj}\nabla_kv^i-C^{ik}\nabla_kv^j
 =-\frac{C^{ij}-g^{ij}}{\lambda_r}.
\]

共変微分を組み合わせたこの輸送・変形の演算では接続係数が打ち消し合う．
そのため `upperConvectedRHS` を偏微分と添字の縮約から定義できる．
円筒の曲率は計量を用いる応力発散と運動量方程式に残る．

半径 1〜2 の二次元環状領域で，内筒の速度は 1，外筒は固定する．
内筒は `t=12…14` で滑らかに減速し，その後停止する．
`ηs=0.04, ηp=0.16, λr=1.5, ρ=1`．初期値は定常 Couette 解に
角度による速度と高分子の向きの小さな変動を加える．
半径方向 49 点・円周方向 128 点，`dt=1/3840` で `t=24` まで計算する．
軸方向の変化は含まない．動画は環状領域での高分子応力の大きさと速度の矢印，
平均速度の半径分布，運動・高分子エネルギーの推移を示す．

速度は渦度と流れ関数（速度を微分で表すスカラー場）から求める．
円周方向の平均流は別に時間発展させ，環状領域の循環を保つ．
壁の渦度は流れ関数と速度境界値から求める．
高分子の輸送には生成コードの風上差分を使い，変形は `F C Fᵀ`，
緩和は平衡テンソルとの凸結合で進める．この分割時間積分は 1 次精度で，
負の固有値を切り上げる補正は用いない．座標速度の絶対値も `.fme` で計算する．
緩和時間を含む物理パラメータはすべて `.fme` の宣言を参照する．

検証では解析的な定常解 `vθ=(4/r−r)/3` と
`Crr=1, Crθ=λr γ, Cθθ=1+2(λr γ)², γ=−8/(3r²)` を使う
（ここで示す成分は長さ 1 の直交基底での値）．
輸送とテンソルの時間変化を独立な成分式と比較し，時間刻みを細かくした場合の収束も測る．
全保存時刻で速度の発散と `C` の最小固有値を検査する．

### 3．全球面で緩和する液晶

ネマチック液晶では分子の向き `d` と `−d` を同じ配向として扱う．
対称・トレースゼロの接平面上の二階テンソル `Q` が，この向きと配向の強さを表す．
球面上の Landau–de Gennes 型の緩和方程式

\[
 \partial_t Q^{ij}=\mathcal P_0\left[
 L\nabla^k\nabla_k Q^{ij}+(A-BQ_{kl}Q^{kl})Q^{ij}\right],
 \quad L=0.02,\ A=1,\ B=2
\]

を解く．`𝒫₀` は計量で計算したトレースを取り除く演算である．
これは受動的な配向緩和モデルであり，周囲の流体や活動的な応力は結合していない．
接続係数の計算，二階テンソルの共変微分，三階テンソルの微分と縮約，
トレースの除去をそれぞれ利用者定義の演算子として合成する．

初期値は全球 Cartesian 座標の滑らかな行列場を各接平面に射影して作る．
動画には球の表裏を同時に表示し，色は配向の強さ，線は配向方向，水色の点は欠陥を示す．
線は矢印にせず，`d` と `−d` の等価性を表す．
欠陥は表示のために動かすのではなく，計算した `Q` の周りの向きの回転から検出する．

二つの重なる球座標（Yin–Yang 格子）で極の座標特異点を避ける．
座標の間ではテンソルの両方の添字を基底変換してから補間する．
球面を平面としてつなぎ合わせたり，穴を開けたりはしない．
各座標は 33×81 点，時間積分は 2 次 Runge–Kutta 法を用いる．

検証には，Cartesian 座標で一定の対称行列を球面の接平面に射影してトレースを除いた場を使う．
この場ではテンソルのラプラシアンが `−2Q` になる．
基準分割 24→48→96 の誤差と，独立な成分実装との差を測る．
時間発展では有限性，トレースゼロ，配向の強さ，欠陥の指数の総和 `+2` を検査する．
