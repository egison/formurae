# 自由表面を含む波の長時間計算

## 現状

`examples/wave_train/wave_train.fme` は，D2Q9（二次元・九速度の格子ボルツマン法）で
3つの初期波を浅瀬へ進ませる．416×64点，4,200ステップの標準条件では，
3波が沖側と浅瀬の観測点を通過し，波頭の覆いかぶさりと岸への乗り上げが生じる．
全期間の水量は相対変化1.19×10⁻¹⁴未満に保たれた．

2026-09-17の追加試行では，次の2条件が流速0.3未満の検査に失敗した．

1. 粘性を下げ，間隔を広げた480×64点の試行は，4,800ステップを予定したが
   4,320ステップ，最大流速0.30168で停止した．
2. 624×96点の試行は，6,300ステップを予定したが4,410ステップ，
   最大流速0.30064で停止した．水量の保存だけではこの問題を検出できない．

後者の保存場では，3,390ステップの格子位置(63,63)に，水の占有率約0.0226の
孤立した水面点が残り，記録された流速が約0.2347となっていた．
現在の分類では，水点に接しない低占有率の水面点でも，質量が `threshold*rho` より
大きければ残る．このような点の輸送・消滅と流速の増加の関係を調べる必要がある．
試行の設定と停止時の記録は `examples/wave_train/results/trials.json` に残している．

## 欠けているもの

- 孤立した水面点を含む，格子より小さい水の部分の一貫した取り扱い．
- 水面の再分類で近傍の受け取り手がなくなった質量について，保留場 `bank` に残る
  量の合計と，その時間変化を含む検査．現状は各点の最大絶対値を報告する．
- 長時間計算の安定性と，格子を細かくした場合の波形・到達時刻・水量の比較．

## 設計判断

Formura本体を拡張せず，初期条件，分類，質量移送，診断のすべてを `.fme` に書き，
通常の生成経路を使う．外部の粒子計算や専用Cソルバーを追加しない．
速度の切り詰めや `bad` の判定から問題の点を除外するだけで安定化済みとしない．
分類条件，分布の再構成，未解像の水の取り扱いを先行研究と照合し，
質量の消失や非局所の瞬間移動を生まない方法を検討する．

## 差し込み口

- `wave_train.fme` のStage 1の `proposal` とStage 2の `nextKind`．
- Stage 3の質量再配分・分布初期化と `bank`．
- Stage 4の診断場と `run.py` のFormura集計設定，`driver.c` の出力．
- `verify.py` に同じ問題を再現する小さい独立の初期条件を加える．

次のコマンドで失敗した試行を再現できる（標準の掲載デモを上書きしない）．

```sh
python3 examples/wave_train/run.py --grid 480 64 --steps 4800 --every 20 \
  --param center=230 --param waveSpacing=90 --param beachStart=265 \
  --param gaugeOffshoreX=255 --param gaugeSurfX=325 --param tau=0.54 \
  --output .build/wave_train/low-viscosity-trial

python3 examples/wave_train/run.py --grid 624 96 --steps 6300 --every 30 \
  --param depth=36 --param amplitude=26.25 --param center=270 --param width=18 \
  --param beachStart=323 --param gravity=0.00006666666666666667 --param tau=0.62 \
  --param waveSpacing=105 --param gaugeOffshoreX=308 --param gaugeSurfX=413 \
  --output .build/wave_train/fine-trial
```

## 完了条件

- 上記2条件を予定した終了時刻まで検査範囲内で実行できる．
- 孤立した小さな水の部分の試験で，速度・質量・位置の扱いを説明し検査できる．
- 静水，1波，3波の検査を保ち，保留質量も含めた水量保存を確認する．
- 解像度を変えた比較を行い，単に動画の輪郭が滑らかになったことと数値精度の改善を区別する．
