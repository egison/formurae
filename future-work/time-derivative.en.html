Formurae future work: the ∂_t time-derivative notation (considered and rejected)

Design note (2026-07-27). We considered letting u' = u + dt * κ * Δ u be written as ∂_t u = κ * Δ u and decided against it. The conclusion and the design principle are recorded in §7 of the GPCE draft (the “Explicit time stepping” paragraph); this note preserves the full counterexamples, the rejected alternatives, and the suite measurements.

1. Summary — the ∂_t form does not determine the update

The proposal was to replace the explicit update rule

step:
  u' = u + dt * κ * Δ u

by the PDE itself:

step:
  ∂_t u = κ * Δ u

The motivation is symmetry: the spatial side is already written with continuum operators (Δ, curl, ∂_x), so the time axis should match.

The core of the rejection: which values the right-hand side reads (previous or freshly updated) is a property of the scheme, not of the equation. The surface of the ∂_t form cannot recover this information, so it must be brought back by annotations, declarations, or an implicit convention — at which point the “pure PDE” selling point is gone. Moreover, steps such as LBM streaming and diagnostic fields are not semidiscrete flows at all, so the update-rule notation cannot be removed from the language anyway. Duplicating the notation buys nothing worth its cost.

2. Decisive counterexamples — same surface, opposite answers

Two coupled systems that the ∂_t form cannot distinguish demand opposite reference policies.

2.1 The Maxwell pair — the updated value is correct

step:                          -- examples/maxwell3d_yee
  E' = E + dt * curl B
  B' = B - dt * curl E'        -- reading the updated E' is what makes it stable

That B reads the updated E' is the substance of the symplectic-Euler/Yee scheme; the energy stability of the wave system hinges on it. Writing ∂_t B = - curl E erases the choice.

2.2 An exchange system — the previous values are required

∂_t a = k * (b - a)
∂_t b = k * (a - b)            -- the right-hand sides sum to zero → a + b should be conserved

If both sides read the previous values (Jacobi), then a' + b' = a + b holds exactly up to rounding. Under a “use the newest computed value” convention,

a' = a + dt·k(b − a)
b' = b + dt·k(a' − b) = b + dt·k(a − b) + dt²k²(b − a)
⇒ a' + b' = a + b + dt²k²(b − a)

a drift of O(dt²) per step, O(dt) in total by time T. Sequential (Gauss–Seidel) updates are dissipative and hence stabilizing, so nothing blows up: the loss is invisible until you measure the invariant. The written equations claim the sum is conserved while the lowering silently breaks it — the worst kind of silent change.

2.3 Steps that are not semidiscrete flows at all

f11' = pullz 1 p11             -- examples/lbm_d3q19: the streaming half of collide–stream
q'   = divg V                  -- examples/divergence2d: a diagnostic field, no time evolution

These are not ODE integrations, so they cannot be written in ∂_t form; the update-rule notation stays in the language regardless.

3. Alternatives considered and why each was rejected

OptionContentRejection
A. Newest value wins
(freshest-wins)		 Automatically read E' if already computed, E otherwise Silently breaks the conservation law of §2.2. In the suite, pearson3d and tdgl3d silently become a different scheme (§4). Line order acquires meaning while no token at the use site changes, so reorderings do not show in diffs. Jacobi coupling becomes inexpressible (only workaround: local U0 = U hoisting).
B. Integrator declaration
time : euler | symplectic		 Well-defined as method of lines: euler = all previous values; symplectic = update in written order, references to already-updated fields become primed Unambiguous, but under symplectic the equation order still carries meaning, and non-MOL steps remain — so the notation split (two dialects) is unavoidable.
C. Plain = previous + explicit ' on the RHS ∂_t B = - curl E': reuse of the existing prime notation with a static precedence check Zero silent changes, and 31/33 examples would migrate with byte-identical .fmr — but a prime survives, so “written purely as the PDE” fails anyway. Too little return for a duplicated notation.
D. Temporal staggering as a field declaration Declare placement at half-integer time, e.g. field B_i @ dual @ half-time, deriving E vs. E' from placement, order-independently (the temporal analogue of the v2.15 half-integer radii) Mathematically the most honest (it is what Yee is), but it touches the state layout and every layer. Needs a cost/benefit evaluation of the same kind as the general metric. A candidate for future reconsideration.

Under option A (freshest-wins) the meaning of exactly two examples changes silently; both are reaction–diffusion models whose simultaneous (Jacobi) update is intended:

-- pearson3d: U' is computed first, so the U in V's right-hand side turns into U'
U' = U + dt * (Fu * (1 - U) - Fe * U * V^2 + Du * Δ U)
V' = V + dt * (Fe * U * V^2 - Fv * V + Dv * Δ V)

-- tdgl3d: likewise the a in b's right-hand side turns into a'
a' = a + dt * (a - (a^2 + b^2) * a + Δ a)
b' = b + dt * (b - (a^2 + b^2) * b + Δ b)

The other 21 Euler examples survive only by accident — each is single-field, mediated by locals, or references other fields only in the first equation — and a reordering breaks the accident. That fragility is itself the argument against option A.

5. The adopted design principle (recorded in paper §7)

Declarations generate what they uniquely determine; genuine numerical choices stay written in the equations.

Determined by a declaration → generatedNumerical choice → written in the step
Metric coefficients (metric scale / embedding) The time integrator (the shape u' = u + dt * R itself)
Wall closures (boundary x : sbp) Previous vs. updated references (the RHS ')
Staggering parities and widths (profiles / half-integer radii) Artificial dissipation (λ * ∂²_x ρ), SAT penalty terms

The counterpart of the existing slogan “the metric is a declaration, not a fourth notation” is “time integration is an equation, not a declaration.” The continuum equation lives in the model's comment header, as in -- du/dt = kappa * laplacian(u); this note makes that existing habit official.

6. A lexical trap (a caution about the current implementation)

In the current src/Formurae/Pre/Parse.hs, a ∂ whose mark is not a declared axis falls back to the indexed derivative (the same treatment as the j of ∂_j σ~i~j). So writing ∂_t u on a right-hand side today is silently interpreted as a spatial derivative with index t. If ∂_t is ever adopted, t must be reserved as the time mark, and (a) RHS occurrences and (b) collisions with an axis or index named t must become static errors.

7. Conditions for revisiting

  • If Runge–Kutta demand shows up in real examples: a time : rk4 declaration with stage synthesis via locals (the temporal counterpart of composeStages) fits within option B. Even then, prefer a macro/declaration inside the update-rule notation over a ∂_t surface form.
  • Option D (temporal staggering as declaration): a time-placement declaration symmetric to spatial @ primal/@ dual has whole-pipeline impact of the same kind as the general metric (general-metric.en.html), so it needs a dependency map and a cost/benefit evaluation first. If it lands, the primes of the Maxwell pair disappear and the result is order-independent.
  • In either case the exchange system of §2.2 is a mandatory regression test (exact conservation check).
